# VARUN --- WHO AM I? Portfolio

A responsive personal portfolio website for **Varun**, introducing his
work as a developer and entrepreneur.

## Features

-   Futuristic black-and-red visual design
-   Responsive desktop and mobile layout
-   Hero and profile placeholder section
-   About, skills, projects, approach, and contact sections
-   Mobile navigation menu
-   Smooth scrolling and scroll-reveal animations
-   No framework, build tools, or external dependencies required

## Files

-   `varun-who-am-i-portfolio.html` --- the complete standalone website
-   `README.md` --- this project guide

## Run locally

1.  Download or clone the project files.
2.  Keep `README.md` and `varun-who-am-i-portfolio.html` in the same
    folder.
3.  Open `varun-who-am-i-portfolio.html` in a modern browser.

You can also use a local development server, such as the Live Server
extension in Visual Studio Code.

## Customize the website

Open `varun-who-am-i-portfolio.html` in a code editor and update:

-   **Profile placeholder:** Replace the circular `V` avatar in the
    `.avatar` element with your own image.
-   **About section:** Edit the introduction to reflect your current
    experience.
-   **Skills:** Add, remove, or rename skill cards.
-   **Projects:** Update project descriptions and technologies as your
    projects progress.
-   **Social links:** Check the Instagram, Discord, and GitHub URLs in
    the Contact section.
-   **Colors:** Edit the CSS variables inside `:root` near the top of
    the `<style>` block.

The project descriptions are presented as concepts and work in progress
where appropriate. Update them to reflect the actual status before
publishing.

## Publish with GitHub Pages

1.  Create a GitHub repository for the portfolio.
2.  Upload `varun-who-am-i-portfolio.html` and this `README.md`.
3.  Rename the HTML file to `index.html` so it loads as the repository's
    homepage.
4.  In the repository, open **Settings → Pages**.
5.  Under **Build and deployment**, select **Deploy from a branch**.
6.  Choose the `main` branch and `/ (root)` folder, then save.
7.  Wait for GitHub Pages to publish the site. Your website URL will
    appear in the Pages settings.
